# 📖 Jak korzystać z materiałów

W przypadku nauki samodzielnej zalecany jest następujący schemat pracy:

1. Zapoznaj się z materiałem teoretycznym.
2. Przeanalizuj przykładowy kod.
3. Uruchom program we własnym środowisku.
4. Zmodyfikuj przykład.
5. Wykonaj ćwiczenie samodzielnie.
6. Przetestuj rozwiązanie.
7. Porównaj różne sposoby rozwiązania problemu.
8. Wykorzystaj poznane zagadnienia w projekcie.

> Samo przeczytanie kodu nie zastępuje programowania.
> Najważniejszym elementem nauki jest samodzielne tworzenie, uruchamianie, testowanie i poprawianie programów.
